# 띄어쓰기 교정 예시

## 원본 텍스트 (띄어쓰기 없음)
```
요즘너무덥지않나요?여름다시찾온것같요ㅠ빙수넣어놓으려구했는데게으른저..칭찬합니다ㅋㅋㅋ넘더워서빙수다시만들어먹었는데과일통조림은다먹어서없구연유뿌렸더니맛은있네요^^맛있게먹으면0칼리맞죠???^
```

## 교정 후 텍스트 (KoSpacing 적용)
```
요즘 너무 덥지 않나요? 여름 다시 찾아 온 것 같아요 ㅠ 빙수 넣어 놓으려구 했는데 게으른 저.. 칭찬합니다 ㅋㅋㅋ 넘 더워서 빙수 다시 만들어 먹었는데 과일통조림은 다 먹어서 없구 연유 뿌렸더니 맛은 있네요 ^^ 맛있게 먹으면 0칼로리 맞죠??? ^
```

## 두 번째 예시 원본
```
저는오늘남편저녁에김밥해달라고해서간단히재료손질하면서만들어먹었어요~ㅎㅎ다들맛있는점심드셨나요?
```

## 두 번째 예시 교정 후
```
저는 오늘 남편 저녁에 김밥 해달라고 해서 간단히 재료 손질하면서 만들어 먹었어요~ ㅎㅎ 다들 맛있는 점심 드셨나요?
```

KoSpacing 모델은 문맥을 이해하고 한국어 문법에 맞게 띄어쓰기를 적용해 줍니다. 위의 예시처럼 자연스러운 띄어쓰기가 적용된 결과를 얻을 수 있습니다.
